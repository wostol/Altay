# ТФСО — сайт Томской федерации спортивного ориентирования

Прототип главной страницы (MVP) в рамках редизайна сайта федерации.

## Стек (текущий этап)

- React 19 + TypeScript + Vite
- Tailwind CSS 4
- Данные пока захардкожены в `src/data.ts` (новости, соревнования)

Планируемый целевой стек проекта: Next.js, PostgreSQL, Payload/Directus CMS,
Docker Compose — см. план на 2 месяца.

## Структура главной страницы

- Шапка с навигацией (sticky, мобильное меню)
- Hero-блок с иллюстрацией карты БО (`src/assets/orienteer-map-hero.svg`)
- Быстрые ссылки (календарь, результаты, карты, вступление)
- Блок важных объявлений
- Новости (карточки с категориями)
- Ближайшие соревнования (со статусами регистрации)
- Разделы: Результаты / Документы / Клубы
- Контакты + форма обратной связи (заглушка)
- Подвал

Анимации: лёгкое появление блоков при скролле (`Reveal` через IntersectionObserver),
hover-эффекты. Учтён `prefers-reduced-motion`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run lint
```
